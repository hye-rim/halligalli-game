# 할리갈리 🔔

같은 과일이 정확히 5개가 되면 먼저 벨을 누르는 카드 게임. 컴퓨터와 2~4인으로 하거나 방 코드로 친구와 실시간 대결한다. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- 카드 56장: 🍌🍓🍇🍏 네 과일 x 14장 (한 장에 같은 과일이 1~5개: 1개 5장, 2개 3장, 3개 3장, 4개 2장, 5개 1장). 2~4명이 똑같이 나눠 갖고 남는 카드는 뺀다
- 카드는 **자동으로 한 장씩** 넘어간다(서버·컴퓨터가 1.7초마다 차례대로 맨 위 카드를 내 앞 열린 더미에 올림). 사람은 벨만 누른다
- **카드 내기**: 내 차례에는 아래 내 칸이 노랗게 빛나고 제한 시간 막대(1.7초)가 줄어든다. **내 칸을 누르면 바로 카드가 나가고**, 안 누르면 막대가 다 줄었을 때 저절로 나간다(컴퓨터·상대 차례는 예전처럼 자동). 벨이 맞은 직후에는 쓸어 가는 모습을 보여 주는 동안(`TAP_AFTER_RING_MS`, 0.9초)은 눌러도 안 나간다. 온라인은 `flip` 메시지(내 차례일 때만 받음)
- 모두의 열린 더미 **맨 위 카드**에 보이는 같은 과일의 합이 **정확히 5**가 되면 먼저 🔔 을 누른 사람이 열린 카드를 전부 가져가 자기 더미 맨 아래에 깐다. 그 사람부터 다시 넘긴다
- 5가 아닌데 누르면 다른 사람 한 명마다 카드 한 장씩(내 더미 맨 위에서) 나눠 주고 1초 동안 벨이 잠긴다
- 내 더미가 비면 열린 더미를 뒤집어 다시 쓰고, 그것도 비면 탈락. 마지막까지 남으면 승리. 제한 시간(컴퓨터 4분·온라인 6분)이 끝나면 카드가 가장 많은 사람이 이기고 같으면 무승부
- 컴퓨터: 5가 된 뒤 쉬움은 1.3~2.6초, 어려움은 0.5~1.0초에 누르고, 쉬움은 4%·어려움은 0.8% 확률로 가끔 엉뚱하게 잘못 누른다. 3·4인 대전은 컴퓨터가 모두 쉬움이다
- 화면 움직임: 새 카드는 그 사람의 덱(🂠 숫자)에서 뒷면이 날아와 제자리에서 앞면으로 뒤집히고, 벨을 맞히면 깔려 있던 카드들이 이긴 사람의 덱으로 쓸려 간다(`#fx` 층, Web Animations). 탭이 가려져 있거나 `prefers-reduced-motion` 이면 생략
- 컴퓨터를 이긴 횟수는 `halligalliWins` (로비 표시용), 온라인 전적은 `halligalliOnline`
- **온라인 대전**: 빠른 대전(2명) · 방 만들기(2~4명, 방장이 시작) · 4글자 방 코드(초대 링크 `?room=코드`) · 재접속(30초) · 기권(3~4명이면 그 사람의 카드를 나머지가 나눠 갖고 계속) · 한 판 더. **벨은 서버에 먼저 도착한 요청이 이긴다.** 맞힌 직후 0.7초 안에 늦게 온 벨은 벌 없이 무시한다(네트워크가 늦은 사람 보호). 서버가 같은 규칙(`public/logic.js`)으로 판정하고, 남의 뒤집히지 않은 카드는 장수만 보낸다. 방 코드를 짧은 시간에 많이 틀리면 잠깐 막는다
- 튜토리얼 중에는 컴퓨터가 벨을 누르지 않고 카드도 천천히 넘긴다. M 소리, 스페이스·엔터로도 벨

규칙·컴퓨터 반응은 `public/logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력·소리·온라인은 `public/game.js`, 방·매칭·자동 넘김은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(덱 구성·고르게 나누기·넘기기·5개 판정·벨 맞힘/틀림·탈락과 되넘기기·카드 총량 불변(무작위 450판)·시간 종료·결정론), `test/server.test.js`(서버를 띄워 자동 넘김·틀린 벨·벨 경쟁·늦은 벨·2~4명 방·시간 종료·기권·한 판 더·재접속 등, `FLIP_MS`·`RING_PAUSE_MS`·`MATCH_MS` 환경변수로 시간을 줄인다).
